# 🌱 AgroDirect – Farmer to Consumer Platform

## 📌 About the Project

**AgroDirect** is a web-based farmer-to-consumer platform designed to connect farmers directly with customers by eliminating unnecessary middlemen.

The platform helps farmers sell their agricultural products at fair prices while allowing consumers to purchase fresh produce directly from farmers. It promotes transparent transactions, supports regional languages, and makes agricultural products more accessible.

## 🎯 Objectives

- Connect farmers directly with consumers.
- Eliminate unnecessary intermediaries.
- Provide fair pricing for farmers.
- Make fresh agricultural products easily accessible.
- Support regional language interaction.
- Simplify product browsing, ordering, and payment.

## ✨ Key Features

### 👨‍🌾 Farmer Module
- Farmer registration and login.
- Add, update, and manage agricultural products.
- Manage product prices and availability.
- View and manage customer orders.

### 🛒 Consumer Module
- Consumer registration and login.
- Browse available agricultural products.
- Search for products.
- Add products to cart.
- Place and manage orders.
- Choose Cash on Delivery or demo online payment.

### 🛠️ Admin Module
- Admin login and dashboard.
- Manage farmers and consumers.
- Manage product information.
- Monitor platform activities.

### 🎙️ Additional Features
- Voice-based product search.
- Regional language support.
- Audio guidance and interaction.
- Secure authentication.
- Shopping cart and order management.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Bhavana123634/AgroDirect.git
```

### 2. Navigate to the Project Folder

```bash
cd AgroDirect
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Configure the required environment variables and credentials according to the project's configuration.

### 5. Run the Application

Use the start command defined in the project's `package.json` scripts.

```bash
npm start
```

### 6. Open the Application

Open the local URL displayed in your terminal.
